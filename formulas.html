Matrix Operations & Formulas

➕ Matrix Addition

Two matrices can be added only when they have the same number of rows and columns.

Cij = Aij + Bij

Example: 

A = [ 1  2 ]       B = [ 5  6 ]
    [ 3  4 ]           [ 7  8 ]

A + B = [ 1+5   2+6 ]
        [ 3+7   4+8 ]

      = [ 6   8 ]
        [ 10  12 ]

➖ Matrix Subtraction

Corresponding elements of two matrices are subtracted.

Cij = Aij − Bij

✖ Matrix Multiplication

Matrix multiplication is possible when the number of columns in Matrix A equals the number of rows in Matrix B.

Cij = Σ AikBkj

↕ Transpose

In transpose, rows are changed into columns and columns are changed into rows.

ATij = Aji

|A| Determinant

Determinant is calculated only for a square matrix.

For a 2 × 2 matrix: 

A = [ a  b ]
    [ c  d ]

|A| = ad − bc
